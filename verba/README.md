# VERBA — 今日の名言

偉人の名言を毎日1つ表示するPWAです。開いたときは今日の名言だけが、壁紙風に大きく出ます。

- 公開URL: https://65022iwama-blip.github.io/verba/
- 日付で名言が変わります（60件を順に表示）
- その人の顔写真を大きく表示（写真：Wikimedia Commons / Wikipedia、古代の人物は肖像画・彫像）
- 前の日 / 今日 / 次の日 / ランダムで切り替え
- お気に入りは端末の localStorage（verba.favs）に保存
- 一覧は「一覧」ボタンで開く（テーマ別：挑戦・努力・失敗・夢・勇気・学び）
- コピー機能つき
- ダークベース＋目に優しい柔らかいネオン色（CHRONOSと同じ方針）
- 日本語訳は意訳です

## ファイル
- index.html（本体・名言60件＋肖像写真URL内蔵）
- manifest.json
- sw.js（オフライン用、verba-v2）
- icon-192.png / icon-512.png
